# The project

## Problem

Similarly named fields can represent different things. Timestamp formats, units and locally assigned identifiers need their source context before they can be interpreted together.

The solo hackathon prototype explored that software-integration problem in a defence challenge. This account deliberately stays at the artifact and documentation level; it supplies no operational procedures, algorithms, parameters or scenario geometry.

## Retained work

The original project retains application source, a solution write-up, synthetic-scenario testing and audit summaries, and a seven-section explanatory HTML presentation. A later iteration documented a synthetic vision bridge separately.

The original source and full presentation are not included here. Their existence is not a claim that a reviewer can reproduce the application from this repository.

## What the result means

The work produced a documented prototype with controlled-scenario records. Those historical records are not newly reproduced tests, field-accuracy measurements or evidence of live sensor deployment.

The presentation headline reads:

> Five sensors watch the same sky and disagree on everything.

The [screened excerpt](../assets/presentation-excerpt.html) preserves that explanation in a static editorial wrapper. It is not the original seven-section layout or an application screenshot.
