# Historical testing, without an invented benchmark

The retained documents describe supplied challenge tests, regression tests and scenario time steps. Later packaged records also declare suite outcomes. These are different versions and units; they cannot be added into one total or presented as a single freshly reproduced run.

No original application test or new experiment was run to prepare this showcase. File-integrity checks and documentation-layout checks only validate this documentation package.

## What the records support

- The author retained controlled-scenario testing and audit summaries alongside the prototype.
- The project has explanatory material and a documented implementation history.
- Follow-on synthetic bridge work is separate from the original event account.

## What is not established here

- Independent reproduction of any historical test declaration.
- Performance, accuracy or reliability on live field inputs.
- A deployed sensor network, live camera connection or continuous connection to Edge Evidence.
- A runnable application from these repository contents.
- An accepted runtime screenshot of the original application.

An artifact can explain an implementation without verifying its operation. Missing runtime evidence is left visible rather than replaced with a mockup.
